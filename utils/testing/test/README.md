# Тесты 

Есть два вида тестов: regular и edge.
Как следует из названия, regular тесты нацелены на проверку стандартных сценариев использования утилиты.
В свою очередь edge тесты проверяют ее работу в критических условиях и ситуациях, которые теоретически могут с ней произойти  

## Regular тесты

Порядок запуска тестов:

```shell
./regular/create-node.sh

./regular/edit-node.sh

./regular/delete-node.sh

./regular/change-sequence.sh
```
